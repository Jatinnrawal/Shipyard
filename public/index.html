SHIPYARD GUIDE
Help & shortcuts
A quick guide to what this local release control plane can do.

    

      
Release flow
  1. Connect a Git repository from New service.
  2. Choose Docker Compose over SSH, Kubernetes manifests, a Helm chart, or a Jenkins pipeline.
  3. Configure access on the Shipyard host and the target, then deploy from Services or service details.
  4. Review build, deploy, and health-check output in the release logs. Kubernetes and Helm releases can roll back a failed update.

      
The Toolkit generates starter Docker, CI, Jenkins, Kubernetes, and Helm files. Shipyard can directly deploy Docker Compose, Kubernetes manifests, and compatible Helm charts; Jenkins runs your pipeline. It does not create cloud accounts, servers, clusters, DNS, or certificates.
